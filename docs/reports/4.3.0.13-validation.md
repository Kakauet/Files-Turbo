# Files Turbo 4.3.0.13 validation — 2026-10-18

**Status: fixed, verified and closed.** The issue that caused file operations to hang after leaving Files Turbo
open for a long time is fixed. File operations keep working throughout long sessions.

## Fix

The Quick Access enumeration in `WindowsFolder.GetItemsAsync` was already released in a `finally` block.
The file-watcher path in `WindowsRecentItemsService.UpdateRecentItems` also opened a shell enumerator and
retained it after refreshing recent items. The service now releases the folder shell item after binding and
releases the enumerator on completion and failure paths. This prevents the automatic-destinations list from
remaining locked after enumeration.
